# Real-place video worlds: sources and licenses

All four clips are public domain or CC0, so they can be used freely in a free app with no attribution
required. Credits are recorded here anyway, as a courtesy and so the sources can be checked.
Each clip was trimmed, cover-cropped to 1280x720, given a 1.5 s end-to-start crossfade so it loops
seamlessly, stripped of all audio and metadata, and re-encoded as H.264 Main 3.1 yuv420p at 30 fps
with faststart. Each poster `<id>.jpg` (640x360) is a frame taken from its processed clip.

Retrieved: 2026-10-22. Frames were checked by eye: no people, faces, brands or on-screen text in the used ranges.
